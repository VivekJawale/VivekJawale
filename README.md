### ⚡ About me

I'm a software engineer with **3+ years** of experience building **algorithmic trading platforms**. I work across the stack: Golang microservices and real-time data pipelines on the backend, fast data-heavy React interfaces on the front.

- 🚀 **Now:** SDE-II at **Motilal Oswal**, building **StratX**, a platform advisors and clients use to run automated trading strategies
- 📡 Real-time pipelines on **NATS**, live **PnL** and position tracking, order management dashboards
- 🛠️ **Before:** Software Developer at **Novotoc Infotech** on **KEEV**, a no-code algo trading platform (backtesting, forward testing, live trading)
- 💬 Ask me about **Golang, React, real-time systems, trading tech**
